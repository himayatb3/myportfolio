# Himayat Portfolio

## Run
Extract the ZIP and open index.html in your browser. No installation or build step is required.
You can also open this folder in VS Code and use Live Server.

## Edit
- index.html: profile, projects, skills, experience, and contact links.
- style.css: colors, typography, layout, and responsive styles. Main colors are in :root.
- script.js: active navigation, scroll reveals, number counters, scroll progress, hide-on-scroll header, marquee speed, card spotlight, magnetic buttons and cursor ring.

## Motion
All animation respects the visitor's "reduce motion" system setting, and content stays visible if JavaScript fails to load. The cursor ring, spotlight and magnetic buttons only run on devices with a mouse.
The premium styles live at the bottom of style.css under "PREMIUM LAYER".

Keep all three files in the same folder. Google Fonts requires an internet connection; system fonts are used as a fallback.

## Host
Upload index.html, style.css, and script.js to any static web host.
